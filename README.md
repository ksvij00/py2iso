## What is PY2ISO?

**PY2ISO** is a project designed to turn Python projects into bootable ISO images.

Its goal is to simplify the process: run the installer, follow the instructions, and let the installation scripts handle the setup.

## Get started

You don't need to manually perform every setup step. Start with the installation guide and use the installer appropriate for your environment.

<div align="center">

### One command. Start the setup.

```bash
curl -fsSL "https://raw.githubusercontent.com/ksvij00/py2iso/main/installers/install.sh" | sh
```
