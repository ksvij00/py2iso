Choose your operating system. The provided installers handle the setup.

## Linux & MacOS

Open a terminal and run:

```bash
curl -fsSL "https://raw.githubusercontent.com/ksvij00/py2iso/main/installers/install.sh" | sh
```

## Windows

Open **PowerShell** and run:

```powershell
irm "https://raw.githubusercontent.com/ksvij00/py2iso/main/installers/install.ps1" | iex
```

The PowerShell installer handles the remaining setup.

## Manual installation

Clone the repository:

```bash
git clone https://github.com/ksvij00/py2iso.git
cd py2iso
```

View the available installers:

```bash
ls installers/
```

Run the installer appropriate for your operating system.
